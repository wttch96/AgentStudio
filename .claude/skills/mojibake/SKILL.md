## 触发条件

仅在以下情况触发检测：

1. 读取代码文件时，内容显示为乱码、二进制数据或不可读字符
2. 文件头部出现 `GWD`、`GREENSHIELD`、`Encrypted`、`GSD` 等特征
3. 文件内容包含大量非 UTF-8 字符

正常显示的情况下，不触发检测，直接继续。

## 执行流程

使用 git bash 工具 head 、cat 等进行文件读取。
不要进行文件类型判断等，直接先读取1行看看是否乱码。

- 如果git bash 相关的工具也乱码，就停止等待用户处理。
- 如果不乱码就正常处理。

## 注意事项

1. 按需触发，不在每次读取时执行检测
2. 触发后，以后每一次都使用git bash进行文件读写。
